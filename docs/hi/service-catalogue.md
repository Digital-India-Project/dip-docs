# सेवा कैटलॉग मार्गदर्शिका (Service Catalogue)

**दर्शक वर्ग:** ग्राहक, पार्टनर, व्यावसायिक उपयोगकर्ता  
**पहुंच श्रेणी:** Public  
**कार्यान्वयन स्थिति:** Implemented and verified (`DIPINDIA/src/data/catalogue/categories.ts`)  
**अनुवाद स्थिति:** समीक्षित हिंदी (Reviewed Hindi)  
**अंतिम सत्यापन:** 2026-11-27

## सत्यापित 8 सेवा श्रेणियां (`CAT_A` – `CAT_H`)

| कोड | श्रेणी का नाम (`nameHi`) | मुख्य उप-श्रेणियां |
|---|---|---|
| `CAT_A` | व्यक्तिगत एवं नागरिक सेवाएं | पैन और पहचान, पासपोर्ट और यात्रा, वोटर और परिवहन, राज्य प्रमाणपत्र, गजट और डिजिटल वॉल्ट |
| `CAT_B` | व्यवसाय पंजीकरण एवं स्टार्टअप सेवाएं | MSME और GST, कंपनी/फर्म स्थापना, स्टार्टअप/DSC, खाद्य एवं राज्य लाइसेंस |
| `CAT_C` | कराधान एवं अनुपालन सेवाएं | आयकर (ITR), GST रिटर्न, TDS और लेखा, पेरोल और श्रम कानून, ROC अनुपालन |
| `CAT_D` | शिक्षा एवं करियर सहायता सेवाएं | प्रवेश एवं छात्रवृत्ति, परीक्षा फॉर्म, शैक्षणिक सत्यापन, करियर सहायता |
| `CAT_E` | दस्तावेज़ीकरण एवं कानूनी सहायता | शपथपत्र, किराया और व्यवसाय समझौते, अनुवाद और नोटरी समन्वय |
| `CAT_F` | डिजिटल उत्पाद एवं डाउनलोड टेम्प्लेट्स | बिलिंग टेम्प्लेट, एक्सेल टैक्स शीट, चेकलिस्ट और स्टार्टर बंडल |
| `CAT_G` | डिजिटल एवं टेक्नोलॉजी सेवाएं | वेबसाइट और स्टोर, डोमेन/होस्टिंग, ऑटोमेशन, SEO, कस्टम सॉफ्टवेयर |
| `CAT_H` | बी2बी, पार्टनर एवं रीसेलर सेवाएं | पार्टनर ऑनबोर्डिंग, बल्क एवं API वेरिफिकेशन, व्हाइट-लेबल और रेफ़रल |

> [!NOTE]
> सभी सेवा शुल्क, आवश्यक दस्तावेज़, और अनुमानित प्रक्रियाएं लाइव पोर्टल पर चयनित सेवा के विवरण में दिखाई जाती हैं। यहां कोई भी काल्पनिक शुल्क या सरकारी समय-सीमा नहीं दी गई है।
