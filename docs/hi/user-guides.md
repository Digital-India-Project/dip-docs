# भूमिका-आधारित उपयोगकर्ता मार्गदर्शिका (User Guides)

**दर्शक वर्ग:** ग्राहक, पार्टनर, ऑपरेटर, मैनेजर, व्यावसायिक उपयोगकर्ता  
**पहुंच श्रेणी:** Public / Role-Scoped  
**कार्यान्वयन स्थिति:** Implemented and verified (`DIPINDIA/src/lib/rbac.ts`)  
**अनुवाद स्थिति:** समीक्षित हिंदी (Reviewed Hindi)  
**अंतिम सत्यापन:** 2026-11-27

## 1. ग्राहक (`customer`)
- **प्राथमिक टैब:** `मेरा डैशबोर्ड`, `सेवाएं`, `मेरे आवेदन`, `दस्तावेज़ वॉल्ट`, `ट्रैक और मदद`।
- **अनुमतियां:** आवेदन देखना, नया आवेदन बनाना, सुधार के उत्तर देना, और भुगतान स्थिति देखना।

## 2. पार्टनर (`partner`)
- **प्राथमिक टैब:** `पार्टनर डेस्क`, `मेरे ग्राहक`, `सहायक आवेदन`, `कमीशन वॉलेट`, `सेवाएं`।
- **भूमिका:** `individual_agent`, `csc_center`, `franchise`, या `corporate_connector` के रूप में ग्राहकों के लिए आवेदन जमा करना और कमीशन वॉलेट से निपटान (`settlements`) देखना।

## 3. व्यावसायिक उपयोगकर्ता (`business`)
- **प्राथमिक टैब:** `B2B कंसोल`, `API प्लेग्राउंड`, `बल्क वेरिफिकेशन`, `API कुंजी`, `ऑडिट लॉग`।
- **भूमिका:** टीम प्रबंधन, बल्क जॉब्स देखना और API कुंजी घुमाना (`rotate-key`)।

## 4. ऑपरेटर (`operator`) और मैनेजर (`manager`)
- **ऑपरेटर:** `ऑपरेटर डेस्क`, `वॉक-इन आवेदन`, दस्तावेज़ सत्यापन, सुधार अनुरोध भेजना, और अंतिम डिलिवरेबल्स अपलोड करना।
- **मैनेजर:** `SLA Queue`, टीम को कार्य सौंपना (`applications.assign`), ऑपरेटर KYC स्वीकृति (`operators.assign`), `पार्टनर निगरानी`, और `रिपोर्ट्स`।

> [!NOTE]
> सुपर एडमिनिस्ट्रेटर (`super_admin`) और एडमिनिस्ट्रेटर (`admin`) के आंतरिक संचालन एवं सुरक्षा निर्देशों के लिए अंग्रेज़ी मार्गदर्शिका देखें।
