# आवेदन जीवनचक्र और स्थिति मार्गदर्शिका (Application Lifecycle)

**दर्शक वर्ग:** ग्राहक, पार्टनर, ऑपरेटर, मैनेजर  
**पहुंच श्रेणी:** Public  
**कार्यान्वयन स्थिति:** Implemented and verified (`DIPINDIA/src/lib/workflow.ts`)  
**अनुवाद स्थिति:** समीक्षित हिंदी (Reviewed Hindi)  
**अंतिम सत्यापन:** 2026-11-27

## 1. पांच-चरणीय प्रगति मॉडल

`DIPINDIA` में प्रत्येक आवेदन पांच मुख्य चरणों से गुजरता है:
1. **Submitted** (आवेदन जमा)
2. **Payment** (भुगतान पुष्टि)
3. **Verification** (दस्तावेज़ सत्यापन)
4. **Processing** (आवेदन प्रोसेसिंग)
5. **Completed** (पूर्ण एवं प्रमाणपत्र जारी)

## 2. प्रमुख आवेदन स्थितियां

| स्थिति (Status) | प्रगति % | अर्थ |
|---|---|---|
| `Draft` | 10% | ड्राफ्ट सहेजा गया है; फॉर्म और भुगतान अभी बाकी है |
| `Submitted` | 20% | आवेदन जमा हो गया है; प्रारंभिक भुगतान और डेस्क जांच लंबित है |
| `Payment Pending` | 28% | भुगतान पुष्टि की प्रतीक्षा |
| `Payment Confirmed` | 40% | भुगतान सफल; सत्यापन अधिकारी के आवंटन की प्रतीक्षा |
| `Under Review` / `Assigned` | 55% | सत्यापन डेस्क को सौंपा गया है |
| `Documents Required` / `Correction Required` | 52% | उपयोगकर्ता द्वारा आवश्यक दस्तावेज़ या सुधार अपलोड करना बाकी है |
| `Resubmitted` | 65% | सुधारित दस्तावेज़ प्राप्त हुए; पुनः जांच लंबित है |
| `Processing` | 78% | दस्तावेज़ सत्यापित; आवेदन प्रोसेसिंग जारी है |
| `Awaiting External Authority` | 88% | बाहरी प्रक्रिया/अनुमोदन की प्रतीक्षा |
| `Completed` | 100% | आवेदन पूर्ण और जारी किया गया दस्तावेज़ तैयार है |
| `Rejected` / `Cancelled` | 50% / 0% | समीक्षा के दौरान अस्वीकृत या पूर्ण होने से पहले रद्द |
| `Refunded` | 100% | शुल्क वापस किया गया और आवेदन बंद |
